# AgendaContactos
Proyecto desarrollado en Java para administrar contactos mediante un menú por consola.
## Funcionalidades
- Agregar contacto
- Buscar contacto
- Verificar si existe contacto
- Listar contactos
- Eliminar contacto
- Modificar teléfono
- Verificar si la agenda está llena
- Mostrar espacios libres
## Estructura
```text
AgendaContactos
│
├── model
│ ├── Persona.java
│ └── Contacto.java
│
├── service
│ └── Agenda.java
│
├── util
│ └── Validador.java
│
└── app
└── Main.java
```
## Conceptos aplicados
- Programación Orientada a Objetos (POO)
- Herencia
- Encapsulamiento
- Polimorfismo
- Colecciones (Set y HashSet)
- Validaciones
- Sobrecarga de constructores
